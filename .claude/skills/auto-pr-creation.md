# Auto PR Creation Skill

## Purpose

Automatically create GitHub PR after Verification reaches READY FOR PR status using a dedicated PR automation system.

## Usage

This skill is automatically invoked by the post-verification hook when:
- Verification completes with READY FOR PR status
- All safety checks pass

It can also be manually invoked via: `/auto-pr-creation`

## Agent

Uses `.claude/agents/pr-agent.md` for PR preparation and creation.

## Inputs Required

- `verification-report.md` with READY FOR PR status
- `pr.md` (generated by PR agent)
- Clean git working tree
- At least one commit
- Remote repository configured
- GitHub CLI installed and authenticated
- No existing PR on current branch

## Safety Checks

The system performs 10 safety checks before creating the PR:

1. ✓ Verification status is READY FOR PR
2. ✓ All tests pass
3. ✓ Syntax check passes
4. ✓ Git working tree is clean
5. ✓ At least one commit exists
6. ✓ Remote repository configured
7. ✓ GitHub CLI installed
8. ✓ GitHub CLI authenticated
9. ✓ No existing PR on branch
10. ✓ pr.md exists

## Expected Output

When successful:
- GitHub PR created
- PR URL logged and reported
- PR NOT auto-merged

When prerequisites not met:
- Clear error message
- Actionable next steps
- No PR created

## Implementation

The automation system consists of:

1. **Hook**: `.claude/hooks/post-verification-pr.js`
   - Triggers after verification completes
   - Checks READY FOR PR status
   - Prevents duplicate triggers

2. **Script**: `.claude/scripts/auto-create-pr.sh`
   - Performs all safety checks
   - Creates PR using gh CLI
   - Logs all operations

3. **Workflow**: `.claude/workflows/auto-pr-workflow.js`
   - Alternative workflow-based approach
   - Can be invoked manually

## Important Constraints

- **Never auto-merge**: PR is created but not merged
- **Safety first**: All checks must pass before PR creation
- **Real URLs only**: Captures actual PR URL from gh CLI
- **Clean state**: Requires clean working tree and commits
- **Authentication**: Requires gh CLI authentication

## Execution

### Automatic (Default)

After verification completes:
```
/verify → READY FOR PR → Hook triggers → PR created
```

### Manual

Invoke directly:
```bash
# Via skill
/auto-pr-creation

# Via script
bash .claude/scripts/auto-create-pr.sh

# Via workflow
/workflow auto-pr-creation
```
